Welcome to your new SADX Mod! The info below will assist with some additional folders created for your Mod.

Code - You can store your source Code here.
system - SADX's system folder. Store your textures (PVM) here. Stage object layouts are stored here as well.
textures - You can store PVMX and Texture Pack Archives here.

Please refer to the Help drop down in the SA Tools Hub for additional resources or you can reach members for help in the X-Hax Discord.
